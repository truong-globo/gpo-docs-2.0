# Screenshot checklist (internal)

This file is **not** listed in `SUMMARY.md`, so GitBook does not publish it.

Every `<figure>` in these docs currently points at `.gitbook/assets/placeholder.png`. This table is the shooting list. When you capture a real image:

1. Save it as `.gitbook/assets/<id>.png`.
2. Open the page in the **Page** column and change that figure's `src` from `placeholder.png` to `<id>.png`.
3. Tick the **Done** column here.

Rows marked *(optional)* are nice-to-have illustrations, not required.

## How to capture

- Capture on the **production** app in a real Shopify admin, never on a dev build or localhost.
- Viewport at least 1920×1400. Use full-page capture when the subject does not fit.
- No mouse cursor in the frame. Clear any focus ring before capturing.
- Hide the live chat widget and its "Chat with…" bubble completely before capturing.
- Never show a real store's domain, customer names, real people's names, or third-party brand logos. Use demo products.
- Annotate sparingly: a 2px outline plus a soft glow around the app-generated element only. Add a small arrow only when the target could be confused with something similar next to it (one tab among tabs, one card in a grid, one row in a table). Do not annotate a single modal, the only button in a section, or a full-width banner.
