# Overview

Open **Pricing** in the app to see the plans available to your store, compare what each one includes, and switch.

The app is available on the free plan. Paid plans add more option types, configuration options, and features, and each paid plan includes a 14-day free trial.

All features are visible on every plan. Features not included in your current plan are shown but locked, with an upgrade prompt, so you can see what each plan offers.

## Notes

* Billing is handled through Shopify. Charges appear on your Shopify invoice rather than as a separate charge.
* This documentation does not list prices. Pricing varies by pricing version and for Shopify Plus stores, so the **Pricing** page in the app is the only accurate source.
* When you install the app for the first time, it opens on **Pricing** and asks you to select a plan. Select the free plan to continue.
