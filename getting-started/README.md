# Overview

This section takes you from an empty store to a working option on a live product page. Read the pages in order the first time — each one assumes the previous one is done.

## The four things that must happen

An option only appears to a shopper when **all four** of these are true. Most "why can't I see my options?" questions are one of these four being missing.

<table><thead><tr><th width="60">#</th><th width="250">What</th><th>Why it matters</th></tr></thead><tbody><tr><td>1</td><td>The app is installed and a plan is selected</td><td>The app redirects you to the <strong>Pricing</strong> page on first open and will not let you use the rest of it until you choose a plan — the Free plan counts.</td></tr><tr><td>2</td><td>An option set exists, with at least one option in it</td><td>An empty option set cannot be saved.</td></tr><tr><td>3</td><td>That option set has a product rule</td><td>The app needs to know which products it applies to. Without a rule it cannot be saved either.</td></tr><tr><td>4</td><td>The app embed is enabled on your live theme</td><td>This is what actually renders the option on your storefront. Installing the app does not do it for you.</td></tr></tbody></table>

## What you need before you begin

* A Shopify store you can install apps on. If you are a staff member, you need the **Apps** permission; if you are a collaborator, the store owner must approve app installation.
* Access to the theme you want the options to appear on. You will open the Shopify theme editor once.
* At least one product to test with. A draft product is fine for testing, as long as you can open its product page.

{% hint style="info" %}
Nothing in this section changes your theme's code. The app renders through Shopify's theme app extension system, which you switch on and off from the theme editor.
{% endhint %}
