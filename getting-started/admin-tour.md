# Tour of the app

Read this once and you will not have to hunt for a setting again. Nothing here changes your store — it is a map.

## Where the app lives

The app runs inside your Shopify admin. Open it from **Apps** > **Globo Product Options, Variant**, or type the app name into the search bar at the top of Shopify admin.

Because it runs inside Shopify admin, the browser address bar always shows a Shopify URL. Use the app's own menu to move between its pages rather than typing addresses.

## Option Sets

The list of everything you have built. Each row shows the option set's ID, name, status, sales channels, and creation date.

From this page you can search and filter by status, sort, open an option set to edit it, view its analytics, and run bulk actions on a selection — duplicate, delete, set active, set draft, save as template, export. See [Manage option sets](../option-sets/manage-option-sets.md).

The **Create option set** button gives you two choices: **Create from scratch**, or **Use a template**.

## The option set builder

This is where you spend most of your time, so it is worth knowing its four areas.

## Templates

Three tabs:

* **Pre-designed Templates** — complete option sets for common products, ready to copy.
* **Personalized Templates** — the same idea, but with the live preview already configured.
* **Custom Templates** — templates you created or saved from an existing option set.

See [Templates](../templates/README.md).

## Settings

**Settings** opens a page with three tabs across the top:

<table><thead><tr><th width="200">Tab</th><th>Contains</th></tr></thead><tbody><tr><td><strong>Settings</strong></td><td>Three sections: <strong>General</strong> (where the widget appears and how it behaves), <strong>Design</strong> (colours, borders, typography, custom CSS), <strong>Add-on price</strong> (how extra charges are displayed).</td></tr><tr><td><strong>Translations</strong></td><td>The fixed text the widget shows shoppers — button labels, upload prompts, and every validation message — per storefront language.</td></tr><tr><td><strong>Theme Setup</strong></td><td>Choose which theme to work with and turn the app embed on or off for it.</td></tr></tbody></table>

Settings on these pages apply to **every** option set in your store. Anything specific to one option set lives in the builder instead.

## Automations

Workflows that run when an order comes in containing app options. Three kinds:

* **Email notification** — email yourself the order and the options chosen.
* **Order notes update** — write the chosen options into the order's notes.
* **Order tags update** — tag the order, either with a fixed tag or with the value the customer chose.

See [Automations](../automations/README.md).

## Pricing

Plan comparison with a **Monthly** / **Yearly** switch, a full feature-by-feature table, and a discount code field. Your current plan is marked and its button is disabled. See [Change your plan](../plans/change-your-plan.md).

## Contact Us

A support form. It asks for your name and email, a reason for contacting, the page you are having trouble with, your store password if the storefront is password-protected, and your message. Sending it also passes along your store details so we do not have to ask.

If you want us to look inside your admin, the form explains where to find your 4-digit collaborator request code: **Settings > Users and permissions > Collaborators** in Shopify admin.
