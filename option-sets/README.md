# Overview

An **option set** is a group of questions you ask the shopper on a product page — plus the rules for which products, customers, and countries it appears for.

This is where you will spend most of your time in the app.

## How many option sets should I have?

There is no limitation, so aim for whatever keeps your admin readable.

Please note that **each product can only be assigned to one option set**, and the app will always prioritize the **newest option set** when multiple option sets apply.

Therefore, please put **all products that use the same option elements into a single option set** to ensure the correct options are applied.
