# Overview

Open **Pricing** in the app to see the plans available to your store, compare what each one includes, and switch.

The app can be used on a free plan. Paid plans add option types, configuration, and features, and each one includes a 14-day free trial. Every feature is visible on every plan. Features your plan does not include are displayed but locked, with an upgrade prompt, so you can see what each plan adds.

## Notes

* Billing goes through Shopify. Charges appear on your Shopify invoice, not separately.
* This documentation does not list prices. They differ by pricing version and for Shopify Plus stores, so the **Pricing** page in the app is the only accurate source.
* On a new install, the app opens on **Pricing** and asks you to select a plan. Selecting the free plan is enough to continue.
